# Express Blog Routing

API Express per un blog con routing organizzato: router e controller per i post, con operazioni CRUD e filtro per titolo. Dati in memoria.

## Tecnologie

- Node.js
- Express 5
- JavaScript

## Avvio

```bash
npm install
npm start
# oppure in sviluppo
npm run dev
```

Server su `http://localhost:3000`.
